# tools

Здесь собираю всякие небольшие инструменты и скрипты, которые упрощают мне жизнь и избавляют от повторяющейся рутины.

Например, каждый раз на свежей Ubuntu для настройки терминала приходилось:

1. Устанавливать Git, Curl и Zsh.
2. Идти за командой установки Oh My Zsh.
3. Искать инструкцию для Powerlevel10k и устанавливать тему.
4. Править `.zshrc` и выбирать Zsh оболочкой по умолчанию.

В какой-то момент меня задолбало повторять это вручную — так появился `p10k.sh`.

По мере необходимости буду добавлять сюда другие мелкие инструменты, которые однажды написал, чтобы больше не делать что-то руками.

## p10k.sh

Автоматизирует установку Zsh, Oh My Zsh и Powerlevel10k на Ubuntu:

- Проверяет и устанавливает недостающие программы.
- Создаёт `.zshrc`, если файла ещё нет.
- Выбирает Zsh оболочкой по умолчанию.
- Устанавливает Oh My Zsh и подключает Powerlevel10k.

### Запуск

Нужны установленный `curl` и права `sudo`. Запускать от своего пользователя:

```bash
bash -c "$(curl -fsSL https://raw.githubusercontent.com/typoakk/tools/main/p10k.sh)"
```

После установки запусти `zsh`. Если мастер настройки темы не открылся автоматически, выполни `p10k configure`.
